# REQUIREMENTS TRACEABILITY MATRIX — MA TRẬN TRUY VẾT YÊU CẦU

Bảng đối chiếu chuẩn: Mã yêu cầu → Hiện trạng → File liên quan → Thay đổi cần làm → Kiểm thử nghiệm thu (AT).
Quy ước hiện trạng:
- **Đã có**: Đã tồn tại trong source code và đáp ứng yêu cầu.
- **Có một phần**: Đã có nền tảng cơ bản nhưng thiếu phạm vi chi nhánh, thiếu chốt chặn backend hoặc thiếu tính năng.
- **Chưa có**: Chưa có bảng, entity, service hoặc giao diện tương ứng.
- **Chưa xác minh**: Cần môi trường tích hợp hoặc kiểm thử thực tế để khẳng định.
